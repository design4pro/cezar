Default models lets you select the model Cezar uses for each runner. A configured model applies to manual runs, automations, workflow steps, and continuations, overriding model pins on those launches. Auto selects the lowest-cost-looking available model from the runner catalog. If the catalog has no low-cost hint, Cezar uses its first available model. With no catalog answer, Cezar falls back to the runner's native default.

## Where to find it

Settings → project → Agents → Default models

## How to use it

1. Connect the provider.
2. Select a model or auto (default) in its row.
3. Start a task, automation, or workflow; the selected model is used for that runner.

> **Good to know**: When `modelsLocked` is active, the panel only displays the model from the agent's native settings.
